# Paper Game Planning

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임 제목 | **PaperGame(가명)** |
| 장르 | 퍼즐 던전 방탈출 |
| 개발 엔진 | Unreal Engine 5.4.4 |
| 플랫폼 | PC |
| 플레이 방식 | Single Player |
| 시점 | Top View |
| 예상 플레이 시간 | 10~15분 |

### 한 줄 소개

> 던전에서 퍼즐을 풀어 탈출하는 게임

---

## 2. 게임 컨셉

여러 층으로 이루어진 던전에 떨어진 주인공은 탈출을 위해 퍼즐을 풀어나간다.

던전 내부에는 여러 기믹의 퍼즐이 등장, 플레이어는 해당 층의 아이템이나 기믹을 이용해 막힌 길을 뚫어 출구로 나아가야 한다.

여기서 주인공은 2D로 이루어져 있으며 던전은 보통 3D로 이루어져 있어 이를 활용한 기믹들이 등장한다.

각 층별 퍼즐을 해결하며 올라가 마지막 층의 퍼즐까지 해결해 출구로 나간다면 최종적으로 게임을 클리어하게 된다.

### 핵심 키워드

- **2D/3D** : 2D의 특징을 3D배경에 조합하여 기믹 해결
- **Explore** : 던전 아이템/기믹 탐색
- **Collect** : 퍼즐 해결에 필요한 아이템 획득
- **Puzzle** : 탐색한 것들을 이용해 퍼즐 풀이
- **Escape** : 탈출구 도착 및 게임 클리어

---

## 3. 게임 목표

플레이어의 최종 목표는 다음과 같다.

1. 던전을 탐색한다
2. 주어진 아이템/기믹을 이용해 퍼즐을 분석한다
3. 퍼즐을 풀어 길을 뚫고 나아간다
4. 탈출구까지 이동한다.
5. 그렇게 반복하여 마지막 층까지 탈출 시 게임 클리어

---

## 4. Core Gameplay Loop

게임의 핵심 플레이 흐름은 다음과 같다.

```text
탐색
  ↓
분석
  ↓
필요하다면 아이템 획득
  ↓
퍼즐 해결
  ↓
길이 열림
  ↓
탈출
````

플레이어는 게임이 종료될 때까지 **탐색 → 분석 → 해결 → 이동**의 과정을 반복한다.

## 5. 플레이어 조작

| 입력            | 기능              |
| ------------- | --------------- |
| W / A / S / D | 캐릭터 이동          |
| Mouse         | 선택/사용을 위한 조작           |
| Left Click    | 선택              |
| Right Click   | 사용              |
| Space         | 점프(빠질 수도 있음)              |
| Shift         | 달리기(빠질 수도 있음)             |
| E             | 아이템 획득 / 문 상호작용 |

---

## 6. 플레이어 기능

### 6.1 이동

플레이어는 Top View 방식으로 던전 내부를 자유롭게 이동할 수 있다.

주요 기능:

* 위 / 아래 이동
* 좌 / 우 이동
* 마우스 시점 회전
* 점프
* 달리기
